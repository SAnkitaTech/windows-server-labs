# Group Policy Administration

My Group Policy study notes and Windows Server labs for **ankita.com**.

## Suggested Reading Order

1. [Group Policy Fundamentals and Troubleshooting](fundamentals/README.md) — GPO structure, default policies, LSDOU, GPUpdate, and GPResult.
2. [Active Directory OUs and Applying Group Policy](../03-active-directory-ou-and-group-policy/README.md) — OU structure, linking, Control Panel and removable storage restrictions, security filtering, and testing.
3. [Group Policy Preferences](preferences/README.md) — policies versus preferences, refresh behavior, and item-level targeting.
4. [Windows Defender Firewall Lab](windows-defender-firewall/README.md) — configure and verify the Domain profile firewall policy.
5. [Folder Redirection Lab](folder-redirection/README.md) — redirect Documents for HR users and verify the network location and file access.
6. [Block Registry Editor Using Group Policy](registry-block/README.md) — apply and verify a user policy for the HR OU.

Specific policy labs are documented separately for easy revision.
